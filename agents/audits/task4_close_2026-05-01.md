### Phase E — Bug fix in `sendSetToneMapping`

One-line code change in `src/ui/player/MpvBackend.cpp`:

```cpp
// Was:
setFlag(m_mpv, "hdr-peak-decay-rate", peakDetect);
// Now:
setFlag(m_mpv, "hdr-compute-peak", peakDetect);
```

Reasoning: `hdr-peak-decay-rate` is a numeric mpv option (default 100ms decay), not a boolean. Setting it as a flag silently no-op'd. The proper boolean is `hdr-compute-peak`. Mirrors libplacebo's `pl_peak_detect_params` toggle on the ffmpeg side at `gpu_renderer.cpp:234`.

**Runtime impact today: zero** — no caller passes `peakDetect` to this function (FilterPopover tone-mapping picker is dead per Phase A Q4). The fix is precautionary; future Task 9 (FilterPopover wire-up) makes it load-bearing.

Build: `BUILD OK` (909s full link).
