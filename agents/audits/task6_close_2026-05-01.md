## Deliverables

### (1) sendSetSubtitlePositionMode — Force toggle wired to mpv
- **Was:** `setOpt(m_mpv, "sub-ass-override", ...)` not called; Force mode logged a one-time warning and was a no-op.
- **Now:** `mode == "force"` → `setOpt("sub-ass-override", "force")`; `mode == "standard"` → `setOpt("sub-ass-override", "no")`.
- **Effect:** Force toggle in SettingsPopover now actually overrides authored ASS positioning on mpv (e.g., aggressive-MarginV scripts get pulled to mpv's sub-pos / sub-margin-y).
- **File:** src/ui/player/MpvBackend.cpp:1009-1027 (~15 LOC; comment + 1-line setOpt).

### (2) sendSetSubtitlePixelOffset — pixel offset wired to sub-margin-y
- **Was:** `emit subtitleOffsetChanged(pixelOffsetY)` only — UI got an echo but the value never reached mpv.
- **Now:** `setDouble(m_mpv, "sub-margin-y", static_cast<double>(pixelOffsetY))` plus the existing UI echo.
- **Effect:** pixel-offset slider now moves subs on mpv natively.
- **File:** src/ui/player/MpvBackend.cpp:1057-1069 (~10 LOC).

### (3) sendSetSubtitleUrl — URL subtitle delay + offset wired
- **Was:** `/*offsetPx*/ /*delayMs*/` arguments were comment-marked-as-ignored after the `sub-add` command.
- **Now:** after `sub-add`, applies `delayMs/1000.0` to `sub-delay` if non-zero; applies `offsetPx` to `sub-margin-y` if non-zero.
- **Effect:** loading external URL subtitles with offset/delay arguments now applies both on mpv path.
- **File:** src/ui/player/MpvBackend.cpp:1052-1071 (~15 LOC; argument unwrapping + 2 conditional setDouble calls).

### (4) Pattern A FIX — track-id stringify in MpvBackend track-list parser
- **Discovered via smoke** when Hemanth's right-click Subtitles submenu showed only Off + Load external on Vinland — embedded tracks were absent.
- **Root cause:** mpv emits track-list with `id` as JSON **int**; ffmpeg sidecar emits as JSON **string**. VideoPlayer's `mergeTrackList` reads `id` via `t["id"].toString()` — int returns empty string — every track gets skipped at the `if (id.isEmpty()) continue;` filter. m_subTracks ends empty. The right-click Subtitles submenu, the SubtitlePopover, and the auto-track-pick logic all see no embedded tracks.
- **Fix:** in `MpvBackend::handlePropertyChange` track-list branch (line ~606+), clone the per-track JSON object and overwrite `id` with `QString::number(...)` BEFORE appending to the audio/sub QJsonArrays. Output shape now matches the ffmpeg sidecar's IPC payload.
- **Hemanth verbatim verification:** "subttiles appear and they work" after the build #2 relaunch.
- **Note on default-track convention:** Vinland S02E01, Saiki Ep 11, and Apothecary S02E01 (the 3 baseline anime files) all mark **Signs/Songs/Forced as the file's default sub track**. mpv (correctly) honors this. User picks Dialogue/Full/CR via the now-functional Subtitles popover or right-click menu. Task 6.B queued for cross-playlist track-id carry-forward (today carry-forward only carries lang).
- **File:** src/ui/player/MpvBackend.cpp:606-642 (~15 LOC; QJsonObject clone + key insert).
