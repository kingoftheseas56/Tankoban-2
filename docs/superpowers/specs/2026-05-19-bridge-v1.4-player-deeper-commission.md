# Bridge v1.4 — Player-Side Deeper Commission Spec

**Commissioned by:** Agent 3 (Codex)
**Date:** 2026-05-19
**Schema bump:** v1.3 → v1.4 (lands after D.1 books v1.3)
**Pre-requisite:** D.0 dispatcher delegation refactor + D.1 v1.3 books-side landed

## Strategic intent

Agent 3 has v1.0 player commands (play-file, close-player, get-player, scan-videos, get-videos) but they're surface-level. The deeper command surface — audio/subtitle track selection, decoder stats, screenshot capture, HUD state, sidecar deep state, IPC latency — is what Agent 3 needs for autonomous smokes on player work. Currently these queries require pywinauto pixel reads + sidecar log greps, which Hemanth has to coordinate.

This commission adds ~28 commands across the player + sidecar + subtitle/OSD surfaces.

## Command catalog (28 commands)

Baseline (20 commands per main spec §Detailed catalog Track B v1.4):

Tracks + delay:
- `player-get-audio-tracks` — track list with codec + language + default flag
- `player-get-subtitle-tracks` — same shape for subs
- `player-select-audio-track <id>` / `player-select-subtitle-track <id>`
- `player-set-audio-delay <ms>` / `player-set-sub-delay <ms>`
- `player-set-sub-size <delta>` / `player-set-sub-position <y-offset>`

Chapters + volume + speed:
- `player-get-chapters` / `player-seek-chapter <id>`
- `player-set-volume <0-100>` / `player-set-speed <0.25-4.0>`

HUD + decoder stats + canvas:
- `player-get-hud-state` — chips, time labels, focus indicator
- `player-get-decoder-stats` — drops, queue depth, decoder type
- `player-get-canvas-size` — pixel dimensions
- `player-screenshot <path>` — canvas PNG capture
- `player-simulate-seek-drag <position>` — synthetic QSlider event

Sidecar deep state:
- `sidecar-get-process-state` — alive? pid? memory?
- `sidecar-get-current-stream-info` — codec, fps, bitrate, resolution, hwaccel
- `sidecar-get-decoder-queue` / `sidecar-get-render-queue` — queue depths
- `sidecar-restart` — graceful diagnostic restart
- `subs-get-active-track` / `subs-get-positioning` / `subs-get-fonts-loaded`
- `osd-get-state` — overlay state

Additional from Codex audit gap-fill (8 commands):
- `player-pause` / `player-resume` / `player-toggle-play` — direct lifecycle controls
- `player-seek <seconds>` / `player-frame-step <forward|back>` — sidecar seek and frame-step
- `player-stop` — stop playback without closing player window
- `player-set-mute <true|false>` / `player-get-volume-state` — mute + volume together
- `player-set-aspect <mode>` / `player-set-crop <mode>` — inspect and drive existing aspect/crop state (in VideoPlayer::devSnapshot already)
- `player-get-loading-overlay` / `player-get-buffering-state` — LoadingOverlay + stream-stall state
- `player-get-keybindings` — active player shortcuts and custom keybinding state
- `sidecar-get-ipc-latency` — expose `SidecarProcess` IPC latency counters from `out/ipc_latency.log`
