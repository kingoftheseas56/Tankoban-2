**Commissioned by:** Agent 5 (Codex)

## Strategic intent

Agent 5 (Library UX + Theme) currently has no dev-bridge surface. Library-side work — theme application, density slider, Continue Reading strip state, root folder management, scan triggering, mode pill state — requires UI clicks today. This commission unlocks autonomous Library smokes via 15 new commands across the cross-mode library surface.

## Command catalog (15 commands)

Baseline (10 commands per main spec §Detailed catalog Track B v1.6):
- `library-get-continue-reading <mode>` — CR strip state per mode (comics/books/videos/stream)
- `library-get-recently-added <mode>` — recent strip
- `library-get-search-state <mode>` — library search overlay state
- `library-apply-theme <theme-id>` — runtime theme application
- `library-get-active-theme`
- `library-set-density <density-id>` — tile density slider
- `library-get-settings` — all settings dump
- `library-set-setting <key> <value>` — settings poke (write-capable)
- `library-get-active-mode-pill` — which top-bar mode is active
- `dump-ui library`

Additional from Codex audit gap-fill (5 commands):
- `library-trigger-scan <mode>` / `library-get-scan-state <mode>` — expose scanning state for books, comics, videos, and stream-local files
- `library-get-root-folders <mode>` — inspect the root folder list through CoreBridge
- `library-get-active-layer <mode>` / `library-reset-mode <mode>` — verify the standing topbar-pill reset contract (per `feedback_mode_pill_resets_to_root.md`)
- `library-set-sort <mode> <key>` / `library-get-sort <mode>` — expose per-mode sort keys
- `library-get-selected-items <mode>` — report current tile/list selection for context-menu smokes

## Constraints

- **Additive only.** Schema versioning per `DevControlServer.h:24`.
- **Write-capable commands** (`apply-theme`, `set-density`, `set-setting`, `trigger-scan`, `set-sort`, `reset-mode`) — gated by `--dev-control`. Per Codex anti-pattern #9, `set-setting` is generic (any key) so it needs an allowlist of writable keys OR a write-enable flag. Default to read-only allowlist; document writable keys explicitly in command help.
- **Cross-mode parameter:** every library-* command takes `<mode>` as either CLI positional or in payload — values `comics`, `books`, `videos`, `stream` map to per-page dispatch.
- **`library-reset-mode <mode>`** — verifies the `feedback_mode_pill_resets_to_root.md` contract: every mode's topbar pill resets to root. Use existing `resetToRoot()` slots on each page.
- **ASCII-only emissions** per Rule 16.
- **Build_check.bat = BUILD OK** before commit.
