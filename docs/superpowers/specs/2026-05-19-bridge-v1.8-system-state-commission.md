## Strategic intent

Beyond the per-domain bridges, the brotherhood needs cross-cutting introspection for diagnostics that aren't tied to one page: modal/window/focus awareness, settings + JsonStore + cache direct access, log tailing with correlation marks, sidecar deep state, theme introspection, perf counters, fault injection for resilience smokes. This commission adds 25 commands that any agent can use regardless of their domain.

The single biggest unlock here is `log-mark <label>` — a correlation marker that inserts a labeled line in all log streams simultaneously, so multi-source log analysis post-smoke can pivot on the marker. Without this, agents grep multiple logs by timestamp guesswork.

## Constraints

- **Additive only.** Schema versioning per `DevControlServer.h:24`.
- **Instrumentation prerequisites (per main spec §v1.8 Codex-added block):**
  - `network-list-requests` and `network-get-active` need a shared QNetworkAccessManager observer. Codex must check if one exists; if not, add minimal hooks rather than faking responses.
  - `perf-get-frame-times`, `perf-get-cpu-usage`, `perf-get-gpu-usage` need explicit counters. Return `unsupported` until instrumentation lands; do NOT fake values from process uptime.
  - `cache-get-stats` can start with layers that expose real counts (PosterCache, EdgeTTS LRU, VideosScanner duration cache, AniList/MangaUpdates/BookWalker disk caches). Hit-rate fields should be omitted until the layer records hits and misses.
  - `settings-set`, `jsonstore-set`, `cache-clear`, `network-throttle-set`, `network-block-host`, `dev-inject-error`, `dev-toggle-feature` are write-capable. Default to read-only allowlist; destructive writes require a `TANKOBAN_DEV_WRITE=1` env var second flag (separate from synthetic UI's `TANKOBAN_DEV_UI_SIM=1`).
- **`log-mark` writes to ALL active logs simultaneously:** `out/sidecar_debug_live.log`, `out/stream_telemetry.log`, `out/events.jsonl`, `out/ipc_latency.log`. Format: `\n=== MARK: <label> @ <ISO ts> ===\n`. Idempotent — repeated calls just add more markers.
- **`log-tail` component allowlist:** `sidecar` (sidecar_debug_live.log), `telemetry` (stream_telemetry.log), `events` (events.jsonl), `ipc` (ipc_latency.log), `tankoctl` (any tankoctl.log if it exists). Reject unknown components.
- **ASCII-only emissions** per Rule 16.
- **Build_check.bat = BUILD OK** before commit.
- **Anti-pattern #9:** generic state writes can bypass app invariants. Document writable-key allowlist in command help; `settings-set` rejects keys not on the allowlist with `WRITE_KEY_NOT_ALLOWED` error.
