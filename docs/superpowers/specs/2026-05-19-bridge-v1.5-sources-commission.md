# Bridge v1.5 — Sources-Side Commission Spec

**Commissioned by:** Agent 4B (Codex)
**Date:** 2026-05-19
**Schema bump:** v1.4 → v1.5
**Pre-requisite:** D.0 dispatcher delegation refactor (can land in parallel with D.1 v1.3 books since file sets don't overlap)

## Strategic intent

Agent 4B (Sources — Tankorent + TankoLibrary) currently has no dev-bridge surface. Sources work — indexer health monitoring, queued downloads, search dispatch, download lifecycle — requires UI clicks today. This commission unlocks autonomous Sources smokes via 17 new commands covering search + indexer health + download lifecycle.

## Command catalog (17 commands)

Baseline (10 commands per main spec §Detailed catalog Track B v1.5):
- `sources-search-tankorent <query>` — fire a Tankorent search
- `sources-search-tankolibrary <query>` — fire a TankoLibrary search
- `sources-get-indexer-health` — per-indexer status, response time, error rate
- `sources-get-pending-downloads` — Tankorent download queue
- `sources-cancel-download <id>`
- `sources-force-indexer-refresh <indexer-id>`
- `sources-get-tankorent-state` / `sources-get-tankolibrary-state`
- `dump-ui sources` / `dump-ui tankorent` / `dump-ui tankolibrary`

Additional from Codex audit gap-fill (7 commands):
- `sources-add-magnet <uri>` / `sources-add-url <url>` — route through existing Tankorent add paths
- `sources-pause-torrent <infoHash>` / `sources-resume-torrent <infoHash>` / `sources-remove-torrent <infoHash>` — TorrentClient lifecycle controls
- `sources-set-speed-limits <infoHash|global> <down> <up>` / `sources-set-queue-limits <downloads> <uploads> <active>` — speed + queue settings dialogs programmatically
- `sources-get-tankolibrary-results` — current TankoLibrary result rows, media tab, filters, sort, selected detail
- `sources-open-tankolibrary-detail <result-id>` / `sources-download-tankolibrary-selected` — drive detail/download flow without a click
- `sources-cancel-search` — call existing Tankorent/TankoLibrary cancel paths
- `sources-set-tankolibrary-filters <json>` — expose media tab, English-only, audio format, sort settings already persisted through QSettings

## Constraints

- **Additive only.** Schema versioning per `DevControlServer.h:24`.
- **Write-capable commands** (`add-magnet`, `add-url`, `pause/resume/remove-torrent`, `set-*-limits`, `set-filters`) — gated by `--dev-control`. Per Codex anti-pattern #9, these can bypass UI invariants; document the gate clearly in command help.
- **Don't centralize `IndexerHealth.*` into a new file** unless the plan deliberately calls for it — per Codex audit, the current state lives in `TorrentIndexer` and centralization is a separate refactor decision.
- **ASCII-only emissions** per Rule 16.
- **Build_check.bat = BUILD OK** before commit.
